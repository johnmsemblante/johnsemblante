# Homepage portrait

## Responsive image

The homepage displays the complete graphite portrait immediately. The browser preloads a responsive 400px or 640px AVIF and can fall back to the original transparent WebP. Update both AVIF sizes when replacing the source artwork.

## Site-wide cursor

The root layout, shared by the main portfolio, venture pages, tools and dashboard, provides a black dot and trailing ring for desktop mouse input. The ring expands over links. The dot and ring stay visible over the portrait while hovering. Form fields, touch, forced colours and reduced motion retain native pointer behaviour.
